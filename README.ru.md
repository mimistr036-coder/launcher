# ПРОВИНЦИЯ RP — своя «ГТА мобайл» по схеме Black Russia

Мобильная GTA-подобная игра с **русским городом** (не самповская карта): лаунчер, кэш,
выделенный сервер, мультиплеер. Всё на бесплатном движке **Godot 4.3+**, вся графика
города генерируется кодом — в проекте нет ни одного чужого ассета.

```
┌─────────────┐   HTTP: version.json    ┌──────────────────────┐
│  ЛАУНЧЕР    │ ──────────────────────► │ Сервер обновлений    │
│  (APK/EXE)  │ ◄────────────────────── │ (updates/www, :8090) │
│             │   game.pck (кэш)        └──────────────────────┘
│  ИГРАТЬ ────┼──────────────┐
└─────────────┘              ▼
                load_resource_pack(user://cache/game.pck)
                             │
┌────────────┐   UDP 7777    ▼
│  ИГРА      │ ◄──────────►  Выделенный сервер (godot --headless)
│  (из кэша) │   игроки, машины, чат
└────────────┘
```

## Структура репозитория

| Папка | Что это |
|---|---|
| `game/` | Проект игры: русский город «Провинцинск», персонаж, машины, мультиплеер. Экспортируется в кэш `.pck` |
| `launcher/` | Лаунчер: новости, проверка версии, скачивание кэша с прогресс-баром, запуск игры |
| `server/` | Выделенный сервер (headless, ставится на ПК или VDS) |
| `tools/` | `build_cache.py` — сборка кэша; `serve_updates.py` — сервер обновлений; `pck.py` — упаковщик PCK |
| `updates/www/` | Готовый кэш `game.pck` + `version.json` + `news.json` (раздаётся лаунчерам) |
| `.github/workflows/ci.yml` | CI: автотесты города, мультиплеера и лаунчера на каждом пуше |
| `ci-logs/` | Логи последних автотестов CI |

## Обновления автоматически через GitHub 🔄

CI после каждого зелёного теста публикует кэш и APK в [Release «latest»](https://github.com/mimistr036-coder/launcher/releases/latest):
`game.pck`, `version.json`, `news.json`, `provinciya-launcher.apk`, `provinciya-launcher.exe`.

**Лаунчер по умолчанию качает обновления прямо оттуда** — сервер обновлений на ПК больше не нужен:
- установил APK один раз → дальше лаунчер сам проверяет и докачивает новый кэш при каждом запуске;
- если ты вписывал свой адрес в НАСТРОЙКАХ — нажми «ИСТОЧНИК: GITHUB (авто)», чтобы вернуться к авто-обновлениям;
- для мультиплеера всё ещё нужен игровой сервер (твой ПК по LAN или VDS) — он раздаёт не кэш, а игровую сессию.

## Быстрый старт (10 минут, всё на своём ПК)

Нужно: [Godot 4.2+](https://godotengine.org/download) (обычная версия, не .NET; проверено на 4.0 и 4.3 — кэш совместим) и Python 3.

**1. Собери кэш** (Godot не нужен, упаковка на чистом Python):
```bash
python3 tools/build_cache.py        # Windows: python tools\build_cache.py
```

**2. Запусти сервер обновлений** (для лаунчеров):
```bash
python3 tools/serve_updates.py      # покажет твой IP, например http://192.168.1.50:8090
```

**3. Запусти игровой сервер**:
```bash
# Linux/macOS
server/run_server.sh --port=7777
# Windows (укажи в переменной GODOT_BIN путь к Godot_console.exe или положи godot в PATH)
server\run_server.bat --port=7777
```

**4. Запусти лаунчер** в редакторе Godot: открой `launcher/project.godot` → F5.
В настройках (кнопка «НАСТРОЙКИ») впиши адрес из шага 2 (`http://ТВОЙ_IP:8090`) →
«ПРОВЕРИТЬ ОБНОВЛЕНИЯ» → кэш скачается → «ИГРАТЬ».

**5. В игре**: введи ник, IP сервера (`127.0.0.1`, если играешь на том же ПК), порт 7777 → «ПОДКЛЮЧИТЬСЯ».
Друг с телефона в той же Wi-Fi сети подключается к `http://ТВОЙ_IP:8090` и к серверу по твоему IP.

## Телефон (Android)

**Способ 1 — готовый APK из CI (не нужен ни Godot, ни Python):**
1. Открой вкладку **Actions** в репозитории → последний зелёный запуск → внизу **Artifacts** → скачай `provinciya-launcher`.
2. Внутри — `provinciya-launcher.apk`. Скинь на телефон и установи
   (Android спросит разрешение «устанавливать из неизвестных источников» — разреши).
3. Телефон и ПК должны быть в **одной Wi-Fi сети**.
4. (Один раз) Разреши входящие подключения на ПК — запусти cmd **от администратора**:
   ```bat
   netsh advfirewall firewall add rule name="RP updates 8090" dir=in action=allow protocol=TCP localport=8090
   netsh advfirewall firewall add rule name="RP game 7777" dir=in action=allow protocol=UDP localport=7777
   ```
5. На ПК запусти `python tools\serve_updates.py` (и игровой сервер, если хочешь мультиплеер).
6. В лаунчере на телефоне: **НАСТРОЙКИ** → впиши адрес с экрана serve_updates (например `http://192.168.0.160:8090`) → **ПРОВЕРИТЬ ОБНОВЛЕНИЯ** → **ИГРАТЬ**.

> Проверка: открой `http://IP_ПК:8090/version.json` в браузере **телефона** — если видишь JSON, лаунчер тоже скачает. «Ошибка код 0» = телефон не достучался: сервер не запущен, другой Wi-Fi, или брандмауэр Windows.

**Способ 2 — собрать APK самому в Godot:** `Настройки редактора → Экспорт → Android`
(укажи SDK/JDK, создай debug-keystore, скачай «Шаблоны экспорта») → Проект → Экспорт → Android → APK.

> Для игры через интернет позже: перенеси `serve_updates.py` (TCP) и сервер игры (UDP 7777)
> на VDS и укажи публичный IP — см. ниже.

## Свой VDS (Ubuntu)

```bash
# на сервере (например, в /opt/rrp)
apt install -y python3 unzip
# скачай Godot 4.3 linux и положи как /opt/rrp/Godot_v4.3-stable_linux.x86_64
# скопируй сюда: server/, tools/, updates/
chmod +x run_server.sh
SRV_PORT=7777 ./run_server.sh                 # проверка
cp rrp-server.service /etc/systemd/system/    # автозапуск
systemctl enable --now rrp-server

# сервер обновлений (кэш + новости), например через systemd или screen:
cd updates/www && nohup python3 -m http.server 8090 >/dev/null 2>&1 &
```
Открой порты: **UDP 7777** (игра), **TCP 8090** (кэш). В лаунчерах у игроков впиши
`http://IP_СЕРВЕРА:8090`. Новый кэш выкладывается так: локально `python3 tools/build_cache.py`
и скопируй `updates/www/` на VDS — лаунчеры сами увидят новую версию и скачают.

## Управление

**Телефон**: слева — джойстик (ходьба/руль), справа — кнопки: БЕГ, ПРЫЖОК, СЕСТЬ/ВЫЙТИ,
ЧАТ, РАБОТА. В машине: ГАЗ, ТОРМОЗ, ДРИФТ. Камера — свайп по правой половине экрана.

**ПК**: WASD — движение, SHIFT — бег, ПРОБЕЛ — прыжок/ручник, E — сесть/выйти,
T — чат (`/list` — кто онлайн), J — работа, H — гудок, ESC — меню.

## Свои модели и билды (для творцов) 🛠

### Добавить свою 3D-модель (машину, дом, дерево)
1. Смоделируй в Blender (или скачай готовую) и экспортируй в **`.glb`** (File → Export → glTF 2.0, галочка +Y up).
2. Положи файл в `game/models/` (папку можно создать).
3. Подключи в игре: открой `game/project.godot` в Godot → в коде (например `city_builder.gd`) добавь спавн:
   ```gdscript
   var my_model = load("res://models/my_car.glb").instantiate()
   add_child(my_model)
   my_model.position = Vector3(10, 0, 20)
   ```
   Для своей **машины**: добавь запись в `game/br/car_types.gd` (размеры/скорость) — а модель подключается в `vehicle.gd` вместо боксов.
4. Собери кэш: `python tools/build_cache.py` — модели/текстуры/звуки подхватываются автоматически.
5. Проверь локально: запусти лаунчер с адресом своего ПК. Или закоммить и запушь — CI проверит и опубликует в релиз, все игроки обновятся автоматически.

### Собрать самому APK/EXE (без CI)
1. Скачай [Godot 4.3+](https://godotengine.org/download) (обычный, не .NET).
2. EXE-лаунчер: открой `launcher/project.godot` → Проект → Экспорт → Windows → «Экспорт проекта».
   APK: там же Android (нужен Android SDK + JDK; Godot подскажет при первом экспорте).
3. Если собрал новый лаунчер — просто замени exe/apk. Кэш лаунчер обновит сам.

### Файлы лаунчера на ПК (чтобы на рабочем столе был только .exe)
- Лаунчеру нужен **только `provinciya-launcher.exe`** — `game.pck` с релиза скачивать вручную НЕ надо, он приедет сам.
- Кэш хранится не рядом с exe, а в данных пользователя:
  `%APPDATA%\Godot\app_userdata\Провинция RP — Лаунчер\cache\` (Win) / `~/.local/share/godot/app_userdata/...` (Linux).
- Настройки (адрес сервера): там же, файл `launcher.cfg`. Если лаунчер ведёт себя странно — удали его, он создастся заново с авто-GitHub.

## Как менять игру

- **Город** — `game/br/city_builder.gd`: сетка кварталов (`GRID`, `P`), типы кварталов
  (площадь, школа, АЗС, парк, гаражи…), панельки, деревья, лавочки. Генерация детерминирована
  (фиксированный сид) — у всех игроков город одинаковый.
- **Машины** — `game/br/car_types.gd`: размеры, скорость, разгон. Добавь свой тип — он
  сразу начнёт спавниться.
- **Цикл дня/ночи** — `game/br/day_night.gd` (`DAY_LEN` — сутки за 10 минут).
- **Работа курьера** — `game/br/job.gd`, **чат** — `game/br/hud.gd`,
  **сеть** — `game/br/net.gd` + `server/net_server.gd` (менять только парой!).
- **Новости лаунчера** — `updates/www/news.json`.

После правок: `python3 tools/build_cache.py` — версия кэша поднимется сама
(если код менялся), лаунчеры игроков скачают обновление.

## Готовые сборки без установки Godot

Каждый запуск CI (вкладка **Actions** в репозитории) собирает в джобе **apk** готовые:
- `provinciya-launcher.apk` — ставится на Android (Настройки → разрешить установку из неизвестных источников);
- `provinciya-launcher.exe` — для Windows.

Скачай во вкладке Artifacts последнего зелёного запуска. В лаунчере впиши адрес сервера обновлений — и всё работает.

## Автотесты (CI)

На каждый пуш GitHub Actions скачивает Godot 4.3 и проверяет:
1. **Офлайн** — город строится, машины и точки работ на месте;
2. **Мультиплеер** — сервер поднимается, клиент подключается, получает снапшоты;
3. **Лаунчер** — проверка версии → скачивание кэша → проверка md5 → запуск сцены игры из `.pck`;
4. **Совместимость** — тот же лаунчер под Godot 4.0 (скрипты кэша не должны использовать preload из PCK — на 4.0 он не работает, только runtime-`load()`).

Логи — в `ci-logs/`. Свежий кэш CI коммитит сам.

## Траблшутинг

| Проблема | Решение |
|---|---|
| Лаунчер: «Сервер обновлений недоступен» | Проверь адрес в НАСТРОЙКАХ, что `serve_updates.py` запущен и порт 8090 открыт (Windows: разреши Python в брандмауэре) |
| В игре: «Сервер недоступен» | Игровой сервер запущен? Порт **UDP** 7777 открыт? IP верный (не http://)? |
| Телефон не видит ПК | Оба в одной Wi-Fi; IP ПК можно узнать: Windows `ipconfig`, Linux `ip a` |
| Низкий FPS | Меню → ПАУЗА → Графика: Низкая |
| Кэш повреждён | В лаунчере нажми «ПРОВЕРИТЬ ОБНОВЛЕНИЯ» (перекачает) |
