# ПРОВИНЦИЯ RP — своя «ГТА мобайл» по схеме Black Russia

Мобильная GTA-подобная игра с **русским городом** (не самповская карта): лаунчер, кэш,
выделенный сервер, мультиплеер. Всё на бесплатном движке **Godot 4.3+**, вся графика
города генерируется кодом — в проекте нет ни одного чужого ассета.

```
┌─────────────┐   HTTP: version.json    ┌──────────────────────┐
│  ЛАУНЧЕР    │ ──────────────────────► │ Сервер обновлений    │
│  (APK/EXE)  │ ◄────────────────────── │ (updates/www, :8090) │
│             │   game.pck (кэш)        └──────────────────────┘
│  ИГРАТЬ ────┼──────────────┐
└─────────────┘              ▼
                load_resource_pack(user://cache/game.pck)
                             │
┌────────────┐   UDP 7777    ▼
│  ИГРА      │ ◄──────────►  Выделенный сервер (godot --headless)
│  (из кэша) │   игроки, машины, чат
└────────────┘
```

## Структура репозитория

| Папка | Что это |
|---|---|
| `game/` | Проект игры: русский город «Провинцинск», персонаж, машины, мультиплеер. Экспортируется в кэш `.pck` |
| `launcher/` | Лаунчер: новости, проверка версии, скачивание кэша с прогресс-баром, запуск игры |
| `server/` | Выделенный сервер (headless, ставится на ПК или VDS) |
| `tools/` | `build_cache.py` — сборка кэша; `serve_updates.py` — сервер обновлений; `pck.py` — упаковщик PCK |
| `updates/www/` | Готовый кэш `game.pck` + `version.json` + `news.json` (раздаётся лаунчерам) |
| `.github/workflows/ci.yml` | CI: автотесты города, мультиплеера и лаунчера на каждом пуше |
| `ci-logs/` | Логи последних автотестов CI |

## Быстрый старт (10 минут, всё на своём ПК)

Нужно: [Godot 4.3+](https://godotengine.org/download) (обычная версия, не .NET) и Python 3.

**1. Собери кэш** (Godot не нужен, упаковка на чистом Python):
```bash
python3 tools/build_cache.py        # Windows: python tools\build_cache.py
```

**2. Запусти сервер обновлений** (для лаунчеров):
```bash
python3 tools/serve_updates.py      # покажет твой IP, например http://192.168.1.50:8090
```

**3. Запусти игровой сервер**:
```bash
# Linux/macOS
server/run_server.sh --port=7777
# Windows (укажи в переменной GODOT_BIN путь к Godot_console.exe или положи godot в PATH)
server\run_server.bat --port=7777
```

**4. Запусти лаунчер** в редакторе Godot: открой `launcher/project.godot` → F5.
В настройках (кнопка «НАСТРОЙКИ») впиши адрес из шага 2 (`http://ТВОЙ_IP:8090`) →
«ПРОВЕРИТЬ ОБНОВЛЕНИЯ» → кэш скачается → «ИГРАТЬ».

**5. В игре**: введи ник, IP сервера (`127.0.0.1`, если играешь на том же ПК), порт 7777 → «ПОДКЛЮЧИТЬСЯ».
Друг с телефона в той же Wi-Fi сети подключается к `http://ТВОЙ_IP:8090` и к серверу по твоему IP.

## Телефон (Android)

1. В редакторе Godot: `Настройки редактора → Экспорт → Android` — укажи Android SDK и JDK,
   создай debug-keystore (Godot предложит сам), один раз скачай «Шаблоны экспорта».
2. Открой `launcher/project.godot` → Проект → Экспорт → **Android** → «Экспорт проекта» → APK.
3. Установи APK на телефон. В лаунчере впиши IP твоего ПК (та же Wi-Fi) — всё, как у BR:
   лаунчер скачает кэш и запустит игру.

> Для игры через интернет позже: перенеси `serve_updates.py` (TCP) и сервер игры (UDP 7777)
> на VDS и укажи публичный IP — см. ниже.

## Свой VDS (Ubuntu)

```bash
# на сервере (например, в /opt/rrp)
apt install -y python3 unzip
# скачай Godot 4.3 linux и положи как /opt/rrp/Godot_v4.3-stable_linux.x86_64
# скопируй сюда: server/, tools/, updates/
chmod +x run_server.sh
SRV_PORT=7777 ./run_server.sh                 # проверка
cp rrp-server.service /etc/systemd/system/    # автозапуск
systemctl enable --now rrp-server

# сервер обновлений (кэш + новости), например через systemd или screen:
cd updates/www && nohup python3 -m http.server 8090 >/dev/null 2>&1 &
```
Открой порты: **UDP 7777** (игра), **TCP 8090** (кэш). В лаунчерах у игроков впиши
`http://IP_СЕРВЕРА:8090`. Новый кэш выкладывается так: локально `python3 tools/build_cache.py`
и скопируй `updates/www/` на VDS — лаунчеры сами увидят новую версию и скачают.

## Управление

**Телефон**: слева — джойстик (ходьба/руль), справа — кнопки: БЕГ, ПРЫЖОК, СЕСТЬ/ВЫЙТИ,
ЧАТ, РАБОТА. В машине: ГАЗ, ТОРМОЗ, ДРИФТ. Камера — свайп по правой половине экрана.

**ПК**: WASD — движение, SHIFT — бег, ПРОБЕЛ — прыжок/ручник, E — сесть/выйти,
T — чат (`/list` — кто онлайн), J — работа, H — гудок, ESC — меню.

## Как менять игру

- **Город** — `game/br/city_builder.gd`: сетка кварталов (`GRID`, `P`), типы кварталов
  (площадь, школа, АЗС, парк, гаражи…), панельки, деревья, лавочки. Генерация детерминирована
  (фиксированный сид) — у всех игроков город одинаковый.
- **Машины** — `game/br/car_types.gd`: размеры, скорость, разгон. Добавь свой тип — он
  сразу начнёт спавниться.
- **Цикл дня/ночи** — `game/br/day_night.gd` (`DAY_LEN` — сутки за 10 минут).
- **Работа курьера** — `game/br/job.gd`, **чат** — `game/br/hud.gd`,
  **сеть** — `game/br/net.gd` + `server/net_server.gd` (менять только парой!).
- **Новости лаунчера** — `updates/www/news.json`.

После правок: `python3 tools/build_cache.py` — версия кэша поднимется сама
(если код менялся), лаунчеры игроков скачают обновление.

## Автотесты (CI)

На каждый пуш GitHub Actions скачивает Godot 4.3 и проверяет:
1. **Офлайн** — город строится, машины и точки работ на месте;
2. **Мультиплеер** — сервер поднимается, клиент подключается, получает снапшоты;
3. **Лаунчер** — проверка версии → скачивание кэша → проверка md5 → запуск сцены игры из `.pck`.

Логи — в `ci-logs/`. Свежий кэш CI коммитит сам.

## Траблшутинг

| Проблема | Решение |
|---|---|
| Лаунчер: «Сервер обновлений недоступен» | Проверь адрес в НАСТРОЙКАХ, что `serve_updates.py` запущен и порт 8090 открыт (Windows: разреши Python в брандмауэре) |
| В игре: «Сервер недоступен» | Игровой сервер запущен? Порт **UDP** 7777 открыт? IP верный (не http://)? |
| Телефон не видит ПК | Оба в одной Wi-Fi; IP ПК можно узнать: Windows `ipconfig`, Linux `ip a` |
| Низкий FPS | Меню → ПАУЗА → Графика: Низкая |
| Кэш повреждён | В лаунчере нажми «ПРОВЕРИТЬ ОБНОВЛЕНИЯ» (перекачает) |
