# 🌐 VPN Subscription Analyzer & Working Subscription Finder

Утилита и веб-сервер для анализа ссылок на VPN-подписки (**VLESS**, **VMess**, **Trojan**, **Shadowsocks**, **Hysteria 2**), диагностики ошибок провайдеров (лимиты устройств, истекшие сроки) и автоматического поиска, пинг-тестирования и сборки актуальных рабочих подписок.

---

## 🔍 Разбор вашего примера (`myvpnkey.com`)

Вы передали ссылку:
```text
https://myvpnkey.com/sub/sub_b44503f8936a8be5c1567f4470c2dfc6
```

### 1. Что показал детальный анализ этой ссылки:
При декодировании содержимого (Base64) сервис вернул следующие записи:
```text
vless://00000000-0000-4000-8000-000000000001@127.0.0.1:1?encryption=none#⚠️ У вас лимит устройств
vless://00000000-0000-4000-8000-000000000002@127.0.0.1:2?encryption=none#🗑 Удалите лишнее устройство в боте
vless://00000000-0000-4000-8000-000000000003@127.0.0.1:3?encryption=none#@TheMellVpnBot
```
* **Провайдер**: сервис бота **`@TheMellVpnBot`** (MellVPN).
* **Статус**: **Исчерпан лимит устройств**. Вместо реальных рабочих серверов бот выдаёт заглушки на адрес `127.0.0.1`.

### 2. Почему нельзя «подобрать» другие подписки на этом сайте перебором:
* Идентификатор `b44503f8936a8be5c1567f4470c2dfc6` — это **128-битный криптографический MD5-хэш** (32 шестнадцатеричных символа).
* Число возможных комбинаций: $16^{32} \approx 3.4 \times 10^{38}$.
* Даже если отправлять по 10 000 000 запросов в секунду, на подбор случайного чужого токена ушли бы миллиарды лет. Кроме того, защита сервера заблокирует IP уже после 20–30 неудачных запросов.

### 3. Как этот скрипт решает задачу:
Вместо бессмысленного брутфорса приватного сервера скрипт:
1. **Диагностирует переданную ссылку**: выявляет домен, имя бота, статус подписки и выводит сообщение об ошибке.
2. **Ищет и парсит открытые проверенные базы и агрегаторы**: обращается к регулярно обновляемым коллекторам (Barry-far, Vorz1k, Pawdroid и др.) с тысячами актуальных серверов VLESS Reality, Trojan и VMess.
3. **Проводит TCP Ping тест**: подключается к каждому серверу, отсекает мертвые узлы и замеряет пинг в миллисекундах.
4. **Формирует готовую рабочую подписку**: сохраняет её в файлы Base64 и Plain text, а также может раздавать её по локальной ссылке для автообновления в вашем клиенте.

## 🚀 Быстрый старт

### 1. Консольный запуск (CLI)

```bash
# Диагностика вашей ссылки и генерация рабочих серверов:
python3 vpn_finder.py "https://myvpnkey.com/sub/sub_b44503f8936a8be5c1567f4470c2dfc6"

# Только диагностика переданной ссылки (без подбора):
python3 vpn_finder.py --check-only "https://myvpnkey.com/sub/sub_b44503f8936a8be5c1567f4470c2dfc6"

# Поиск только серверов VLESS Reality с лимитом 20 штук:
python3 vpn_finder.py --protocol vless --limit 20

# Экспорт результатов в JSON:
python3 vpn_finder.py --export-json result.json
```

---

### 2. Веб-интерфейс и локальный сервер подписки

Скрипт умеет работать как полноценный локальный сервер подписки:
```bash
python3 vpn_finder.py --serve --port 8080
# или
python3 sub_server.py
```

После запуска:
* **Веб-панель**: откройте в браузере `http://localhost:8080/` (в песочнице доступен через Live Preview).
  - Красивый темный интерфейс.
  - Поле для ввода любой ссылки на подписку.
  - Мгновенная диагностика статуса и ошибок провайдера.
  - Список проверенных рабочих серверов с сортировкой по задержке (пинг).
  - Копирование ссылок в один клик и генерация **QR-кодов** для мобильного телефона.
* **Ссылка для VPN-клиента (автообновление)**:
  - `http://127.0.0.1:8080/sub` — стандартная подписка в формате Base64 (поддерживает `Subscription-Userinfo`, `Profile-Update-Interval`).
  - `http://127.0.0.1:8080/sub/raw` — список сырых ссылок (`vless://...`).

## 📱 Как добавить полученную подписку в клиент

### Поддерживаемые приложения:
* **Windows**: v2rayN, Hiddify, NekoRay, Clash Verge
* **Android**: v2rayNG, Happ, Hiddify, NekoBox, V2Box
* **iOS / macOS**: Streisand, Happ, Shadowrocket, Foxray, V2Box, Hiddify

### Способ 1: Импорт готовых ключей (Base64)
1. Выполните поиск серверов скриптом — будет создан файл `working_sub_base64.txt`.
2. Скопируйте всё содержимое этого файла в буфер обмена.
3. Откройте приложение (например, **v2rayN** или **v2rayNG**) и нажмите **«Импорт из буфера обмена»** (Ctrl+V или кнопка `+` -> `Import from clipboard`).
4. Нажмите **«Проверить пинг / задержку»** и подключитесь к самому быстрому серверу!

### Способ 2: Добавление ссылки на локальный сервер подписки
1. Запустите `python3 vpn_finder.py --serve`.
2. В приложении перейдите в раздел **«Группы подписок» (Subscription groups)**.
3. Добавьте URL: `http://127.0.0.1:8080/sub`
4. Нажмите **«Обновить подписку»** — клиент автоматически загрузит свежий проверенный список серверов.

## 📁 Структура проекта

* `vpn_finder.py` — основной CLI-инструмент и ядро анализа / поиска / пинг-теста.
* `sub_server.py` — веб-сервер с панелью управления и эндпоинтом `/sub`.
* `sources.json` — конфигурация внешних доверенных источников и зеркал с регулярным обновлением.
* `cache_nodes.txt` — встроенная локальная база проверенных серверов (Нидерланды, Германия, США, Франция, Швеция и др.).
* `working_sub_base64.txt` — готовая сгенерированная рабочая подписка в формате Base64.
* `working_sub_raw.txt` — готовые конфигурации в текстовом виде (`vless://`, `trojan://` и др.).
